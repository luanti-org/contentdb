Import categories

Set the categories of many games at once from a CSV file, such as an export of the category review spreadsheet. Each game's categories are replaced; its other tags are kept. Preview first to see what would change.

  • Game: the game's title, or author/name.
  • Main category: a category's title or name.
  • Second category: optional.
  • Link: optional, the game's URL on ContentDB. Used instead of the title when present.
